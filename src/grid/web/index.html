A distributed inference engine that shards a language model across workers, keeps every sequence's memory in fixed-size blocks, and lets requests join and leave the running batch at every step. Everything below is what the engine is doing right now.

Workers are simulated until the real model is connected. The scheduler and cache are real.

Continuous batching

One row per request, one column per step. P is the prefill (the prompt goes in) and d is a decode (one more token). A dotted line is a request waiting for room. When a request finishes, the next one takes its place on the very next step.

Paged KV cache

Every square is one block of tokens. A request takes a block only when its last one is full and gives all of them back when it finishes. The colour is the request that owns the block; the fill is how full it is.
